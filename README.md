## Run
1. Open a terminal in this folder.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open the local address shown by Flask.

## Note
The final performance classifier is trained from the supplied public educational dataset.
The early-warning indicator is a separate transparent pre-examination rule based on the six pre-exam indicators; it is not presented as a model trained on an early-warning target.
